# Slurm Monitor

Native iOS and iPadOS widgets showing the Slurm status of an HPC cluster, fed
by a small middle server that polls slurmrestd.

- `server/` – the middle server (Python)
- `ios/` – the app and its widgets (Swift)
- `docs/contract.md` – the data contract between the two

Under construction. The earlier PyConDE 2025 experiment lives on the branch
`legacy/pyconde-2025`.
